Shop defaults

Amounts are in ₹. Leave a field empty to turn that rule off. Each LIVE campaign is checked on its own against these defaults, unless you set its own values under Campaign-wise limits. Only the daily total adds campaigns together (every campaign that started today in IST).

Auto-stop campaigns

When on, the monitor pauses a campaign for you through Meesho's own pause-campaign request, using your open Meesho tab. Off by default.

How the stop rule works, per campaign:
  1. Below its spend limit → keeps running.
  2. Spend limit reached and no expected ROI set → stopped (hard cap).
  3. Spend limit reached and ROI is below expected → stopped.
  4. Spend limit reached but ROI is at or above expected → keeps running, and ROI is compared again on every check. It's stopped as soon as ROI drops below expected.

Campaign-wise limits

Give any campaign its own spend limit, expected ROI and auto-stop choice. Empty fields use the shop defaults shown in grey. Campaigns appear after a check.

Schedule

Checks happen at a random time inside the interval window, so the traffic looks like a human checking the page. Keep checks infrequent.
